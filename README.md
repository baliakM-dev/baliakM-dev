### Why I built it

The goal is to make AI-assisted development more **structured, reusable and predictable**.

The workflow:

* separates implementation from independent review
* runs security or platform review only when relevant
* supports different workflow levels depending on change risk
* avoids unnecessary agent execution
* keeps project-specific architecture outside the reusable core
* includes validation and behavioral evaluation scenarios
* avoids automatic commit, push, deployment or destructive Git operations
